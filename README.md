# Blessed Finance Management System

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![Tkinter](https://img.shields.io/badge/Tkinter-GUI-success)
![SQLite](https://img.shields.io/badge/Database-SQLite-orange)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

A **desktop-based school finance management system** built with **Python & Tkinter**.  
Manage **students, fees, payments, expenses, notifications, and reports** efficiently with role-based access (admin/staff).

---

## 📌 Features

### Student Management
- Register students individually.
- Bulk import students via Excel.
- View, edit, and delete student records.
- Auto-assign class-based fees.
- View detailed fee info per student.

### Fees & Payments
- Assign fees to students.
- Add or edit payments.
- Track pending fees and payment history.

### Expenses
- Add daily expenses.
- View expense reports.

### Notifications
- Send fee reminders.

### Reports & Analytics
- Generate detailed finance and student reports.
- Dashboard with key metrics:
  - Total collected
  - Pending fees
  - Daily expenses
  - Total students, fees, categories, and classes

### Data Management
- Backup and restore database.
- Role-based access (admin/staff).

## ⚡ Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/holysinner22/Blessed-Finance-Management-System.git
cd Blessed-Finance-Management-System
````

### 2. Install Dependencies

```bash
pip install pandas
```

> Tkinter comes pre-installed with Python.

### 3. Run Application

```bash
python main.py
```
